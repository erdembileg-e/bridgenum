# Монгол дохионы хэлний сайт — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mobile-first static site: landing → catalog (Өгүүлбэр / Үсэг tabs) → full-screen stories viewer per sign, showing only signs whose images exist.

**Architecture:** All content lives in two typed data files (`content/sentences.ts`, `content/letters.ts`); a pure library (`lib/signs.ts`) filters to published items (non-empty `steps`) and computes neighbours. Each sign is its own statically generated page (`/sentence/[slug]`, `/letter/[slug]`) rendering a client `StoryViewer` that steps through images and navigates to the next sign's URL at the end.

**Tech Stack:** Next.js 16.4.5 (App Router, `cacheComponents: true` already on), React 19.3, Tailwind 4, TypeScript; Vitest + Testing Library + jsdom for tests (new dev deps).

**Spec:** `docs/superpowers/specs/2026-11-05-msl-site-design.md`

## Global Constraints

- Read the relevant guide in `node_modules/next/dist/docs/` before writing Next-specific code (AGENTS.md). Known for this version: `params` is a `Promise` and must be awaited; with `cacheComponents` `dynamicParams` is unavailable and `generateStaticParams` **must return at least one param** (empty array = build error `empty-generate-static-params`).
- All UI text Mongolian, plain words; `<html lang="mn">`. Never use "хөгжлийн бэрхшээлтэй", "туслах", "гүүр болох", "өрөвдөх" or similar framing.
- Only owner-made images appear. Never copy anything from any `mnsl-source/` folder into the repo.
- An item with `steps.length === 0` is unpublished: no page (404), no catalog card, no sitemap entry, not counted.
- Colours: primary `#5b3a9e`, light `#e9def7`, page bg `#faf8fd`, stories bg `#1d1530`.
- Font must cover Cyrillic incl. Ө Ү: `next/font/google` `Nunito`, subsets `["latin","cyrillic"]` (replaces Geist).
- Site URL from `NEXT_PUBLIC_SITE_URL`, fallback `https://${process.env.VERCEL_PROJECT_PRODUCTION_URL}`, then `http://localhost:3000`.
- URLs are permanent once shared: sentence slug = content folder name without `NN-` prefix; letter slugs exactly as listed in Task 2.
- Work on branch `feat/msl-site` (not `main`).

## Review Focus

1. Opening an unpublished or unknown slug (`/sentence/saikhan-amarsan-uu`, `/letter/a`, `/sentence/xyz`) → Mongolian 404 page, not a blank viewer. (Task 4 test + Task 5 build check)
2. With only one published sentence, the last step must show "Бүх дохиог үзэх" instead of navigating to a missing page; back button after auto-advance returns to the previous sign (`router.push`, not `replace`). (Task 3 tests)
3. A typo in an image path in the data file must fail tests, not ship a broken image. (Task 2 integrity test)
4. Letters route must build while zero letters are published, and the Үсэг tab must be hidden. (Task 5 build check, Task 6 test)
5. Tapping/swiping must work on a 375px phone without blocking vertical page gestures; arrow keys work on desktop. (Task 3 tests + Task 8 manual check)

  ```ts
  export type SignKind = "sentence" | "letter";

  export type Sign = { kind: SignKind; slug: string; order: number; title: string; steps: Step[]; ogImage?: string };
  export function getPublished(kind: SignKind): Sign[];            // steps.length > 0, sorted by order
  export function getSign(kind: SignKind, slug: string): Sign | null; // null if unknown OR unpublished
  export function getNeighbors(kind: SignKind, slug: string): { prev: Sign | null; next: Sign | null; index: number; total: number }; // among published; index 0-based
  export function signHref(sign: Pick<Sign, "kind" | "slug">): string; // "/sentence/<slug>" | "/letter/<slug>"
  export function allSlugs(kind: SignKind): string[];              // every defined slug, published or not
  ```
