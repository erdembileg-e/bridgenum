# Монгол дохионы хэлийг таниулах вэб сайт — дизайн

Огноо: 2026-11-05

## 1. Зорилго ба яагаад

Монгол дохионы хэлийг (МДХ) **ерөнхий олон нийтэд** таниулж түгээх сайт. Хүмүүс гол төлөв
**Facebook-ээр хуваалцсан линкээр утаснаасаа** орж ирээд **1–5 минут** байна. Тэр хугацаанд
зураг харж, дохионы хэлний тодорхой мэдлэг (хэдэн өгүүлбэр, үсэг) авч гарах ёстой. Танилцуулга
хуудсыг уншсан хүнд **"дохионы хэлийг үнэхээр сурах хэрэгтэй юм байна"** гэсэн санаа үлдэх ёстой.

## 2. Зорилтууд / зорилт биш / болохгүй зүйл

**Зорилтууд**
- Утсанд зориулсан (mobile-first), нэвтрэх шаардлагагүй, хурдан ачаалдаг сайт.
- Танилцуулга хуудас → Каталог (Өгүүлбэр 40 / Үсэг 35) → Stories маягийн алхам алхмаар үзэх харагдац.
- Өгүүлбэр, үсэг бүр өөрийн линктэй, Facebook-т хуваалцахад зураг, гарчигтайгаа гоё харагдана.
- Шинэ дохио нэмэхэд зураг хийж, нэг дата файлд тайлбар нэмэхэд хангалттай байх (компонент, хуудасны код өөрчлөхгүй).

**Зорилт биш (одоогоор)**
- Видео тоглуулах. Хожим нэмэгдэж магадгүй тул өгөгдлийн бүтэц алхам бүрт видео нэмэх боломжтой байна.
- Хэрэглэгчийн бүртгэл, ахиц хадгалах, шалгалт, сэтгэгдэл, хайлт.
- Удирдлагын самбар (CMS), өгөгдлийн сан.

**Болохгүй зүйл (ажиллаж байсан ч бүтэлгүй гэж тооцогдоно)**
- Сонсголгүй хүмүүсийг өрөвдсөн, доромжилсон, "туслах хэрэгтэй хүмүүс" гэж тусгаарласан өнгө аяс.
  "Хөгжлийн бэрхшээлтэй", "туслах", "гүүр болох" зэрэг үг хэрэглэхгүй. Дохионы хэлийг бусадтай
  адил нэг хэл гэж харуулна.
- Хүнд, мэргэжлийн хэллэг. Бүх текст энгийн монгол үгээр бичигдэнэ.
- mnsl.mn-ийн зураг/видео, эсвэл бусдын постерын зургийг сайт дээр гаргах (зохиогчийн эрх).
  Сайт дээр **зөвхөн эзэмшигчийн өөрөө хийсэн зургууд** гарна.

## 3. Хязгаарлалт

- Одоо байгаа төсөл: **Next.js 16.4.5, React 19.3, Tailwind 4, TypeScript**, `app/` router.
  Энэ Next.js-ийн хувилбарт өөрчлөлт их тул код бичихээс өмнө `node_modules/next/dist/docs/`-ийг уншина (AGENTS.md).
- Байршуулалт: `.gitignore`-д `.vercel` байгаа тул **Vercel** гэж үзэв (миний шийдвэр).
- Контент нь `~/Desktop/sign-language-images/`-д байна (доор). Одоогоор шинэ хэв маягийн зураг
  **зөвхөн №1 "Сайн байна уу?"**-д бэлэн (`step-1..3.png`, 880×1172, нэгтгэсэн `*-steps.png` 3200×1268).
  Бусад 39 өгүүлбэр, 35 үсгийн зургийг эзэмшигч хожим ижил хэв маягаар хийнэ.

## 4. Шийдэгдсэн зүйлс (эзэмшигчийн шийдвэр)

### 4.1 Хуудсууд ба урсгал
1. **Танилцуулга (landing)** — `/`. Бага мэдээлэл өгөөд каталог руу шууд чиглүүлнэ.
2. **Каталог** — "Өгүүлбэр (40)" ба "Үсэг (35)" гэсэн 2 табтай.
   - Өгүүлбэр: 2 баганатай карт (зураг + өгүүлбэр).
   - Үсэг: 5 баганатай торон дээр том үсэг.
3. **Stories харагдац** — картанд дарахад бүтэн дэлгэцээр нээгдэнэ. Нэг дэлгэцэнд нэг алхам
   (зураг + тайлбар). Дээд талд алхмын явцыг харуулах зурвас (bar), "N / 40" тоо, ✕ (каталог руу буцах) байна.
   Шударч эсвэл товшиж дараагийн алхам руу шилжинэ. Сүүлийн алхмын дараа дараагийн өгүүлбэр/үсэг рүү шилжинэ.
   Үсгийн табд мөн адил А→Я.

B (каталог) ба C (stories) **нэг сайт дотор хоёулаа** байна.
Зөвшөөрсөн загвар: `.superpowers/brainstorm/*/content/flow-b-to-c.html`.

### 4.2 Танилцуулга хуудасны текст (зөвшөөрсөн)

> **Дохионы хэл бол бас нэг хэл.**

> Монголд 7,800 орчим сонсголгүй хүн бий. Тэд гараар ярьдаг, нүдээрээ сонсдог.
> Харин бидний ихэнх нь тэдэнтэй ярилцаж чаддаггүй.
>
> **Нэг үг сураад үзье.** *(доор нь "Сайн байна уу?" 3 алхам)*
>
> Та одоо нэг дохио мэддэг боллоо. 🙌
> **[ Цааш үзэх → ]** (каталог руу)

### 4.3 Үсэг
- 35 үсэг: А Б В Г Д Е Ё Ж З И Й К Л М Н О Ө П Р С Т У Ү Ф Х Ц Ч Ш Щ Ъ Ы Ь Э Ю Я, тус бүр тусдаа.
- Зураг одоогоор байхгүй. Зураг нь бэлэн болсон үсэг л харагдана (4.4).

### 4.4 Зураг бэлэн болоогүй контент
**Зөвхөн зураг нь бэлэн болсон өгүүлбэр, үсэг** каталог, stories, sitemap-д харагдана. Шинэ зураг нэмэх бүрд
каталог аажмаар томорно. Зураггүй item-д хуудас, линк, Open Graph үүсэхгүй. "N / M" дахь M нь бэлэн болсон
item-ийн тоо. Эхний хувилбарт зөвхөн №1 "Сайн байна уу?" харагдана.
- *Миний шийдвэр:* бэлэн үсэг нэг ч байхгүй бол "Үсэг" таб харагдахгүй. Табын тоо (40/35) бэлэн item-ийн тоогоор харагдана.
- Тиймээс 4.3-т дурдсан placeholder **хэрэглэгчид харагдахгүй**. 35 үсгийн жагсаалт, дараалал нь дата файлд урьдчилан бичигдсэн байна.

### 4.5 Видео
Одоогоор гаргахгүй. Хожим алхам бүрт видео нэмэгдэж болох тул өгөгдлийн бүтэц үүнийг зөвшөөрнө.

## 5. Миний шийдвэрүүд (эзэмшигч шалгана уу)

- **Контентын эх үүсвэр:** зургуудыг төслийн `public/signs/` (эсвэл үүнтэй адил) руу хуулж,
  метадатаг нэг TS/JSON файлд хадгална. Өгүүлбэр бүрт: `slug`, `order`, `text` (кирилл),
  `steps: [{ image, caption, video? }]`. Зураг байхгүй бол `steps` хоосон → тухайн item нийтлэгдэхгүй.
  README.md-ийн 40 өгүүлбэр, фолдерын нэрийг ашиглана.
- **Алхмын тайлбар (caption):** одоогоор `*-steps.png` зураг дотор л бичигдсэн байна (№1-ийн хувьд
  "Баруун гарын алгаа…" гэх мэт). Сайт дээр текстээр харуулахын тулд метадата файлд гараар бичнэ.
  Тухайн алхмын зураг (`step-N.png`) тайлбаргүй тул текстийг HTML-ээр харуулна.
- **Шинэ контент нэмэх арга:** эзэмшигч зургуудаа repo доторх `public/signs/<slug>/step-N.png`-д хийж,
  тайлбарыг нэг дата файлд (`content/signs.ts` маягийн) нэмнэ. Нэг дата файл засах нь зөвшөөрөгдөнө.
  `~/Desktop/sign-language-images/`-ээс автоматаар хуулах скрипт **хийхгүй**, учир нь тэнд mnsl.mn-ийн
  файлууд байгаа бөгөөд тэдгээр нь repo руу хэзээ ч орох ёсгүй. №1-ийн зургийг эхний удаа гараар хуулна.
- **URL:** `/sentence/[slug]` (жишээ нь `/sentence/sain-baina-uu`, тоог хасна), `/letter/[slug]` нь **латин slug**
  (`a, b, v, g, d, ye, yo, j, z, i, i2, k, l, m, n, o, u2, p, r, s, t, u, u3, f, kh, ts, ch, sh, shch,
  hard, y, soft, e, yu, ya` маягаар. Тодорхой жагсаалтыг хэрэгжүүлэгч тогтооно, нэг удаа нийтэлсний дараа өөрчлөхгүй).
  Кирилл URL нь Facebook дээр `%D0%B0` болж муухай харагдах тул латин үсэг сонгосон. Каталог: `/learn`.
- **Stories = item тус бүрийн тусдаа статик хуудас.** Нэг item доторх алхмууд client талд шилжинэ. Сүүлийн алхмаас
  цааш шударвал дараагийн item-ийн URL руу шилжинэ (`/sentence/<next>`). Ингэснээр browser-ийн "буцах" товч ажиллаж,
  линк нь хуваалцах боломжтой хэвээр үлдэнэ. Хамгийн сүүлийн item (№40 эсвэл Я)-ийн дараа каталог руу шилжүүлэх
  "Бүх дохиог үзэх" товч гарна. ✕ дарвал хэзээд каталог руу очно.
- **Хуваалцах линкээр шууд орсон хүн** танилцуулга хуудсыг алгасна, ✕ товчоор каталог руу орж болно.
- **Open Graph:** хуудас бүрт гарчиг (өгүүлбэр), зураг (`*-steps.png` эсвэл эхний алхам; байхгүй бол ерөнхий зураг).
  Үндсэн домэйныг орчны хувьсагчаар (`NEXT_PUBLIC_SITE_URL`) өгнө, байхгүй бол Vercel-ийн URL ашиглана.
- **Хэв маяг:** зургуудын ягаан өнгийг (`#5b3a9e` орчим, цайвар `#e9def7`) үндсэн өнгө болгоно.
  Stories дэлгэцийн дэвсгэр бараан, фонт кирилл үсгийг сайн харуулдаг байна.
- **Хэл:** сайт бүхэлдээ монгол хэлээр, `lang="mn"`.
- **Бүх хуудсыг build хийх үед бэлэн болгоно (static generation),** сервер дээр нэмэлт логик ажиллахгүй.

## 6. Хэрэгжүүлэгчид үлдээсэн зүйлс

- Шудрах (swipe) хөдөлгөөнийг яаж хийх (нэмэлт сан ашиглах эсэх). Гол шаардлага: утсан дээр жигд ажиллах, товших болон гарын сумаар ч ажиллах.
- Зургийг оновчтой болгох (`next/image`, хэмжээ).
- Каталогийн картанд ямар зураг харуулах (эхний алхам эсвэл тусгай).
- Хүртээмж (accessibility): зураг бүрт alt текст (тайлбарыг ашиглана), гараар удирдах.
